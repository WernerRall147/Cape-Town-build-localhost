# Session Details — Build //localhost Cape Town

## Session Title

**Ship It: Build, Test & Deploy AI-Powered Apps with GitHub Copilot and Azure AI Foundry**

---

## Session Abstract

What if you could go from a blank VS Code window to a production-ready, AI-powered cloud application — live, in front of an audience? In this hands-on session, we do exactly that.

We start by installing VS Code and enabling GitHub Copilot, then use Copilot's agent mode to scaffold a real .NET application backed by Azure Cosmos DB — all driven by natural language. From there, we use Copilot to write unit tests, measure code coverage, and open a pull request with an AI-generated summary. We finish by integrating an intelligent AI Agent using Azure AI Foundry and exposing it via a Model Context Protocol (MCP) server — so GitHub Copilot itself can query live data from your application.

No slides. No pre-built answers. Just real, end-to-end developer productivity on stage.

**You'll walk away knowing how to:**
- Set up VS Code and GitHub Copilot for maximum productivity
- Use Copilot agent mode to build a cloud application with Azure Cosmos DB
- Generate tests and enforce code coverage — guided by AI
- Open and review pull requests with GitHub Copilot in the loop
- Build an AI Agent with Azure AI Foundry and expose it as an MCP server
- Ground GitHub Copilot in your own live application data
